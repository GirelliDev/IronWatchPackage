# Dependências e Tecnologias

Resumo
- Backend: Java (Maven), sockets TCP, JSON
- Mobile: Android (Kotlin), Gradle (Kotlin DSL)
- Cliente desktop: Python
- Banco: MySQL

Arquivos importantes
- Raiz: `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`
- Servidor: `pom.xml`
- Admin: `IronWatchAdmin/app/build.gradle.kts`

Checagens sugeridas
- Congelar/lockar versões de dependências em Maven/Gradle
- Configurar CI para rodar `mvn test` e assemble do Gradle
