# Cérebro do projeto — Regras de registro

Data: 2026-04-23T22:09:58-03:00

Este arquivo é o "cérebro" do projeto. Política inicial:

- A cada mudança importante, ou sempre que o usuário solicitar uma alteração, será criado um arquivo .md dentro desta pasta (obsidian/) descrevendo exatamente o que foi feito, por quem (assistente), data/hora e arquivos/modificações relacionadas.
- Esses arquivos servirão como histórico legível e referência central para decisões, alterações, e instruções.
- Nome dos arquivos: definido pelo assistente (timestamp/humano- legível) — confirmar preferência com o usuário.
- Commits no Git: só serão feitos automaticamente se o usuário autorizar explicitamente.

Nota: este é o registro inicial criado para confirmar que a política está ativa.
